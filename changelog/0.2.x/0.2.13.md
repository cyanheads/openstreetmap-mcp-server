# 0.2.13 — 2026-07-09

## Fixed

- **`openstreetmap_query_raw` — `format()` renders every element field in `content[]`, not just the hand-picked ones**: any key beyond `type`/`id`/`lat`/`lon`/`tags` (way `nodes[]`, relation `members[]`, `out meta`/`geom`/`center` fields, etc.) is now appended as `key: value`, with objects/arrays JSON-stringified. Closes the gap where `content[]` silently dropped data `structuredContent` still carried. ([#20](https://github.com/cyanheads/openstreetmap-mcp-server/issues/20))
- **`openstreetmap_geocode` — `nextExcludeIds` emits stable OSM refs instead of the volatile Nominatim `place_id`**: each accumulated token is now `${osm_type[0].toUpperCase()}${osm_id}` (e.g. `N13872184444`, `W555`, `R12345`) when a result carries `osm_type`/`osm_id`, falling back to `place_id` only when it doesn't — `place_id` can change across calls for the same OSM object, which caused pagination to repeat objects already seen. The `enrichmentTrailer.nextExcludeIds` render also gained a `**Next Exclude IDs:**` label so the trailer line self-identifies. ([#25](https://github.com/cyanheads/openstreetmap-mcp-server/issues/25))
