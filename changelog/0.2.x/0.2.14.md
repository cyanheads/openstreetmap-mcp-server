# 0.2.14 — 2026-07-26

## Changed

- **Overpass tool definitions, `overpass-service.ts`, and their tests read `error.data.status`**, replacing the legacy `error.data.statusCode` field the framework's `fetchWithTimeout` no longer emits — `isTransientOverpassError` and the 400/429 remapping in `openstreetmap_query_bbox`, `openstreetmap_query_nearby`, and `openstreetmap_query_raw` now match against the current field.
- **`.gitignore`** anchors the `data/` ignore rule to the repo root (`/data/`) so a `src/**/data/` directory isn't swept up by the pattern.
- **`Dockerfile`** OTEL dependency stage installs with `--omit=dev --ignore-scripts`.

## Added

- **`openstreetmap_geocode`, `openstreetmap_reverse`, `openstreetmap_lookup` — `rate_limited` and `upstream_error` error contracts**, each with a retry/backoff recovery hint, so a 429 or unexpected non-2xx from Nominatim surfaces as a typed, actionable error instead of an opaque `ServiceUnavailable`. `NominatimService` exports a new `isTransientNominatimError` predicate that stops `withRetry` from re-submitting a request Nominatim has already throttle-blocked — a `rate_limited` reason, or a bare 429 with no `Retry-After`, is treated as non-transient and fails fast. ([#32](https://github.com/cyanheads/openstreetmap-mcp-server/issues/32))

## Fixed

- **`NominatimService` — concurrent callers can no longer bypass the 1 req/s throttle**: the next request slot is now reserved synchronously (before any `await`), so N callers arriving together each claim a distinct slot instead of all computing the same delay from a `lastRequestTime` none of them has written back yet. ([#26](https://github.com/cyanheads/openstreetmap-mcp-server/issues/26))
- **`openstreetmap_geocode` — `featureType` search parameter reaches Nominatim**: the service sent it as all-lowercase `featuretype`; Nominatim reads that parameter camel-cased and silently drops unrecognized ones, so the filter was a no-op. ([#31](https://github.com/cyanheads/openstreetmap-mcp-server/issues/31))
- **`OSM_NOMINATIM_BASE_URL` — path prefix is preserved for subpath-hosted mirrors**: `new URL(path, base)` treated a leading-slash endpoint path as absolute, discarding any prefix in the configured base (e.g. `https://host/nominatim`). Endpoints are now joined relative against a slash-terminated base, with or without a trailing slash on the configured URL. ([#34](https://github.com/cyanheads/openstreetmap-mcp-server/issues/34))
