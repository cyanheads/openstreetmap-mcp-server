# 0.2.10 — 2026-07-05

## Fixed

- **`openstreetmap_query_nearby` / `openstreetmap_query_bbox` — Overpass QL metacharacters rejected in tag inputs**: `resolveTagInput()` now rejects `" \ [ ] ; ( )` in the resolved key/value with an `invalid_tag` error, instead of letting them alter the generated Overpass filter — a literal `"` could close the quoted `["key"="value"]` template and inject a second filter. The check runs on the resolved value, so it covers `tag_key`, `tag_value`, and the `amenity` shortcut alike; legitimate OSM characters (letters, digits, spaces, `: _ - . /`, unicode) are unaffected. ([#14](https://github.com/cyanheads/openstreetmap-mcp-server/issues/14))
- **`openstreetmap_query_raw` — missing-`[out:json]` preflight error now carries its recovery hint**: the local preflight check now spreads `ctx.recoveryFor('query_error')` at the throw site, populating `data.recovery.hint` and the text response's `Recovery:` line to match the tool's declared error contract. ([#16](https://github.com/cyanheads/openstreetmap-mcp-server/issues/16))
