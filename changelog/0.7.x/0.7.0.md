# 0.7.0 — 2026-10-26

## Added

- **MCP skill resources:** Publish the openstreetmap-guide skill as an MCP skill resource, with boundary-survey guidance and Overpass QL examples. The guide and reference ship through npm, Docker, plugin installs, and MCPB.
- **Input aliases:** Accept `latitude` / `longitude` on nearby and reverse queries, `radius_m` on nearby queries, and `q` on place searches; send either the alias or canonical name, never both ([#110](https://github.com/cyanheads/openstreetmap-mcp-server/issues/110)).
- **Agent Plugins:** Add root `plugin.json` and `mcp.json` alongside the existing Claude Code and Codex manifests.

## Changed

- **Enrichment text:** Render string values as code literals while preserving their visible values and structured data.
- **Development tooling:** Sync framework guidance and packaging validation, and shorten installation instructions.
- **Dependency age policy:** Set `minimumReleaseAge` to one day.

## Fixed

- **Overpass timeouts:** Distinguish an unfinished successful response body from an endpoint that never answered, including its HTTP status and attempt window ([#108](https://github.com/cyanheads/openstreetmap-mcp-server/issues/108)).
- **MCPB:** Preserve SDK runtime skill modules while removing dependency agent documentation and build-only files.
