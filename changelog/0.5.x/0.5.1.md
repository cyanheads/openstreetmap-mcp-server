# 0.5.1 — 2026-09-17

## Changed

- **All six tool `description`s** are rewritten as single cohesive strings instead of `+`-joined fragments — same tool names and constraints, fewer advertised bytes. The six-tool advertised catalog drops from 50,760 B to 48,528 B, still under the 50,820 B measured ceiling.
- **The server `instructions`** no longer close with the `OSM_NOMINATIM_BASE_URL` / `OSM_OVERPASS_BASE_URL` pointer; both names are still carried by the error recovery hints that call for them.
- **`openstreetmap_lookup_objects`** now documents that it returns only the objects named in `osm_ids`, listing any that resolve to nothing under the pre-existing `not_found` field.
- **The `query_error` recovery hint** on `openstreetmap_query_raw` (and its `docs/design.md` mirror) now points at fixing the specific fault Overpass named in its error message instead of a generic "validate at overpass-turbo.eu" pointer.

## Dependencies

- `zod` ^4.6.4 → ^4.6.5
