# 0.3.2 — 2026-07-29

## Changed

- **`openstreetmap_query_bbox`, `openstreetmap_query_nearby`, `openstreetmap_query_raw`** gain two error contract reasons: `overpass_gateway_timeout` (HTTP 504, keeps the `Timeout` code) and `overpass_unavailable` (other 5xx, keeps `InternalError` for 500/501 or `ServiceUnavailable` otherwise). Both throw via manual `McpError` construction rather than `ctx.fail`, since `ctx.fail` rewrites the code to the contract's declared one and would collapse the two status-mapped codes onto a single value. ([#38](https://github.com/cyanheads/openstreetmap-mcp-server/issues/38))

## Fixed

- **Overpass malformed-query parse errors were truncated before the caller ever saw them** — `OverpassService` now issues the Overpass POST itself via `httpErrorFromResponse` at a 4000-byte body-capture limit, instead of `fetchWithTimeout`'s hard-coded 500 bytes, which lands inside the public endpoint's boilerplate and cuts off before the first `Error:` line at byte 502. The same capture applies to 5xx responses, so a 504/502/503's runtime remark (e.g. "Probably the server is overloaded.") now reaches the error message too. ([#45](https://github.com/cyanheads/openstreetmap-mcp-server/issues/45))
