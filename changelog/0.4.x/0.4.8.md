# 0.4.8 — 2026-09-16

## Changed

- **Advertised catalog** trimmed from 60,412 to 54,777 bytes (~15.1k tokens) by tightening tool, field, and error-contract descriptions across all six tools — no constraint, recovery hint, or cross-tool pointer dropped ([#72](https://github.com/cyanheads/openstreetmap-mcp-server/issues/72)).
- Framework skills moved from `skills/` to `framework-skills/`, so a Claude Code or Codex plugin install no longer hands these development skills to the installing agent.
- `MCP_SESSION_MODE` now defaults to `stateless` via `sessionMode` on `createApp()` rather than the HTTP deployment default; the env var still wins when set.
- Bun engines floor raised to `>=1.4.0`.

## Fixed

- **Caller cancellation** on an Overpass query now classifies as `RequestCancelled` instead of `InternalError` ([#73](https://github.com/cyanheads/openstreetmap-mcp-server/issues/73)).
- **Offset-past-end notice** on `openstreetmap_query_nearby`, `openstreetmap_query_bbox`, and `openstreetmap_query_raw` no longer offers the same retry offset twice when the whole match set fits in one page ([#70](https://github.com/cyanheads/openstreetmap-mcp-server/issues/70)).

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.12.8 → ^0.13.2 (`runToolContract` now rejects out-of-schema tool arguments as `InvalidParams`, matching the production SDK path — [#74](https://github.com/cyanheads/openstreetmap-mcp-server/issues/74))
- `zod` ^4.5.4 → ^4.6.4
