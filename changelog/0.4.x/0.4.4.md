# 0.4.4 — 2026-09-09

## Fixed

- **`openstreetmap_query_raw` bounds each element by a `max_element_bytes` budget (default 20000, UTF-8 bytes)** — a single relation or geometry-heavy way could scale past a client context window even at `limit: 1`; an over-budget element keeps every scalar and its tags but has `members`/`nodes`/`geometry` withheld whole under `withheld_keys`, and `withheldElements`/`withheldNotice` give a one-call retrieval recipe (#60).

## Security

- **Community-edited OSM text is now escaped for literal Markdown display in `content[]` across all six tools** — a Nominatim `name`/`display_name`/address/extratags value or an Overpass tag/name/`members[].role` value could open a heading, forge bold "system notice" text, or emit a raw `<script>` tag inside the server's own response; `structuredContent` is untouched (#61).
