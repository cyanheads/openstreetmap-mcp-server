# 0.4.6 — 2026-09-10

## Added

- **Overpass convenience filters** allow key-existence queries by omitting `tag_value` and up to five ordered `filters` for AND conjunctions in `openstreetmap_query_nearby` and `openstreetmap_query_bbox` ([#65](https://github.com/cyanheads/openstreetmap-mcp-server/issues/65)).
- **Docker run instructions** cover published and local images, container port `3010`, and the build-time telemetry opt-out ([#64](https://github.com/cyanheads/openstreetmap-mcp-server/issues/64)).

## Changed

- **Filter contracts** reject blank values, duplicate trimmed keys, metacharacters, and unknown filter fields, and echo the full chain in enrichment and empty-page guidance.
- **User-Agent example** now uses a version-independent custom identifier while retaining the package-derived default.
