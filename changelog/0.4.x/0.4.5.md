# 0.4.5 — 2026-09-09

## Added

- **`openstreetmap_search_places` accepts `viewbox` (`west`/`south`/`east`/`north`) and `bounded`** — biases results toward a rectangular area, or hard-restricts to it with `bounded: true`. Rejects `bounded` without `viewbox` (`bounded_without_viewbox`) and an inverted or degenerate box (`invalid_viewbox`) before any request is sent; unlike `openstreetmap_query_bbox`, this box does not support the antimeridian. The effective box and restriction mode are echoed via `effectiveViewbox`/`boundedApplied` (#62).
- **A Nominatim HTTP 400 gets its own `invalid_parameters` reason** (`InvalidParams`, non-retryable) on all three Nominatim tools, carrying Nominatim's own `error.message` instead of the generic `upstream_error` base-URL hint. The documented `layer` set and the `exclude_place_ids` token format are now validated at the input schema on `openstreetmap_search_places` and `openstreetmap_reverse_geocode`, so both reproduction cases are rejected before reaching Nominatim (#59).

## Changed

- **`isTransientNominatimError` returns `false` for `data.status === 400`** — a rejected parameter is submitted once instead of retried four times (#59).
- **Enrichment trailers render human labels instead of raw camelCase keys.** `openstreetmap_search_places` labels `effectiveQuery`, `truncated`, `shown`, `cap`, and `tagSelectionCaveat`; `openstreetmap_reverse_geocode` and `openstreetmap_lookup_objects` each gain a trailer labeling `tagSelectionCaveat`; `openstreetmap_query_raw` gains a label for `effectiveQuery`. `structuredContent` is unchanged (#63).

## Fixed

- **`openstreetmap_search_places`'s `truncated` is now a confirmed observation, not an inference from page size** — a same-call `limit + 1` probe to Nominatim proves a further match exists at the query's relevance cutoff before `truncated` is set, so a page that exactly fills `limit` with nothing beyond it no longer reports truncation. `nextExcludeIds` stays gated on the page being full rather than on the probe, since excluding a full page can surface further, less-accurate matches even where the probe found none (#15).

## Dependencies

- None changed.
