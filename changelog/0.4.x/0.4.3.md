# 0.4.3 — 2026-09-02

## Fixed

- **`overpass_unavailable` now throws `ServiceUnavailable` for every non-504 5xx from Overpass** — `openstreetmap_query_raw`, `openstreetmap_query_bbox`, and `openstreetmap_query_nearby` previously surfaced 500 and 501 as `InternalError`, contradicting the reason's declared code.
- **A caller disconnect mid-call now classifies as `RequestCancelled` (-32011)** instead of `InternalError` — applies automatically to in-flight Nominatim and Overpass calls via mcp-ts-core 0.12.4's `fetchWithTimeout` fix.

## Security

- **The SSRF DNS guard now queries both `dns.resolve*()` and `dns.lookup()`** (mcp-ts-core 0.12.4) — closes a Bun-1.4-on-Linux bypass where a hostname only the system resolver could see (`/etc/hosts`, split DNS, an NSS module) passed the guard. Applies to this server's Nominatim and Overpass requests, both routed through `fetchWithTimeout`; no code change required here.
