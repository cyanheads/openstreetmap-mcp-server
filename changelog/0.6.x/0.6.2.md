# 0.6.2 — 2026-10-25

## Changed

- **Markdown output** uses the framework's CommonMark escaper across all six tools; multiline names and names ending in a whitespace-separated hash run render as paragraphs, preserving line breaks, terminal hashes, and nested raw JSON as visible text.
- **Framework errors and enrichment** preserve literal message, recovery, and echo text in Markdown; a handler returning after cancellation settles as `RequestCancelled` (`-32011`).
- **Startup configuration** rejects fractional counts and invalid timer ranges, naming the environment variable responsible, including nested server configuration failures.
- **Development tooling** attributes shared audit advisories to the root-installed dependency version; MCPB bundles exclude development files.
- **Documentation** adds client-specific hosted connection examples, documents `MCP_REQUEST_STATE_KEY`, and synchronizes framework guides.
